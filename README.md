# Snake Game

A lightweight browser-based Snake game built with HTML, CSS, and JavaScript.

## Run it locally

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Arrow keys or `W`, `A`, `S`, `D` to move
- Space to start when the game over overlay is visible
- Click the start button to begin or restart

## Objective

Eat the red food, grow the snake, and avoid crashing into the wall or yourself.
